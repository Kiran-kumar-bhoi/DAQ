## Project Structure

- `src/` - Main MATLAB scripts
- `functions/` - Reusable functions
- `tests/` - Testing
- `data/` - Input data
- `results/` - Results and plots
- `docs/` - Documentation

## Running the Project

Open MATLAB and add the project folders to the MATLAB path before running the main script.
